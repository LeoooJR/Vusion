## :rocket: Getting Started <a name="getting-started">

```bash
# Clone the repository
git clone https://github.com/LeoooJR/Vusion.git

# Make sure you're working in the directory of the cloned repository
cd Vusion

# Get help about Vusion
python ./src/main.py --help

# Launch Vusion with your setup
python ./src/main.py --reference [.fai] --sample [sample] --vcf [id,file,[yaml]] --vcf [id,file,[yaml]] ... --pileup [.pileup] --output [path]
```
